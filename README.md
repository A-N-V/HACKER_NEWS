# ANV News

A clean Hacker News reader built with React, Redux Toolkit and [Mantine](https://mantine.dev).

- Top 100 stories, auto-refreshed every minute
- Sort by rank or by newest, instant search by title, author or site
- Threaded comments with lazy-loaded replies and collapsible branches
- Light and dark themes (follows the system by default)

## Scripts

```bash
yarn          # install dependencies
yarn dev      # start the dev server on http://localhost:3000
yarn build    # type-check and build to dist/
yarn preview  # serve the production build
```
